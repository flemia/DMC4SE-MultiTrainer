# Co-op（2 人プレイ）ガイド

1 つの画面で **2 人同時プレイ**を楽しむための機能です。あなた（P1）の隣に相方（P2）を呼び出し、
**2 本目のコントローラ**で操作できます。

> ⚠️ **実験的な機能（WIP）です。** 一部のステージ・組み合わせで挙動が不安定なことがあります。
> オフラインの練習・お遊び用としてお使いください。

---

## 用意するもの

- **コントローラ 2 本**（P2 用に 2 本目を接続しておく）
  - P1 はいつもの操作（キーボード / 1 本目のコントローラ）
  - P2 は **2 本目のコントローラ**で動かします

> 💡 **離れた友達とオンラインで遊ぶには**: [Parsec](https://parsec.app/) などのリモートプレイアプリを
> 使えば、相手のコントローラがこの PC の「2 本目のコントローラ」として認識され、
> オンラインでも一緒に遊べます（遅延は回線環境に依存します）。

---

## 使い方

1. ミッション中に trainer を開く（**INS** か **F1**）
2. **Game タブ → 「Co-op」** を開く
3. **「Co-op Mode」にチェック**を入れる
  - これだけで カメラ・2 本目コントローラ・ロックオン・相方の HUD が 2 人用にまとめて切り替わります
4. **P1（操作キャラ）** と **P2（相方）** を選ぶ
  - **P1**：あなたが操作するキャラを切り替え
  - **P2**：隣に呼び出す相方のキャラを選ぶ（**P1 と違うキャラでも OK**）
  - P2 を「(なし)」にすると相方を引っ込めます
5. 2 本目のコントローラで相方を動かす

> P1 / P2 の選択は **「Co-op Mode」が ON のときだけ**操作できます（OFF のときはグレー表示）。

---



## できること

- **別キャラの相方を呼べる** — 例：ダンテ＋ネロ、バージル＋トリッシュ など自由な組み合わせ。
- **それぞれ自分のスキルで戦える** — 相方は、そのキャラ本来の解放済みスキルで動きます。
- **画面を 2 分割して遊べる** — **Splitscreen** を ON にすると、上 = P1 / 下 = P2 の 2 画面に分かれ、
それぞれ専用のカメラで遊べます（下記参照）。
- **カメラが 2 人を自動で収める**（分割しない場合）— 2 人（とお互いのロックオン相手）が画面に収まるように、
カメラの位置と引き具合が自動調整されます。**ボス戦もカメラが 2 人を追います**。
- **ロックオンが別々** — P1 と P2 は、それぞれ **自分の近くの敵**にロックオンします。
- **倒れても自動で復活** — 相方が生きていれば、ダウンから数秒で自動蘇生します（下記参照）。
- **相方にも本物の HUD が出る** — 相方の HP・ゲージ・武器表示が、**ゲーム本体の HUD そのもの**で
もう 1 セット表示されます（Co-op ON で自動、下記参照）。
- **敵が 2 人に散らばる** — 敵は近い方のプレイヤーを狙うようになります。
- **相方の技もちゃんと出る** — ネロのスナッチ／バスターの位置や投げる向きが、相方側でも正しく決まります。
- **ステージを移動しても相方が残る** — ステージが切り替わっても、選んでいた相方が自動でまた出てきます
（ボスステージでも自動で出てきます）。
- **対戦もできる** — Friendly Fire / PvP を ON にすれば 2 人で撃ち合い・斬り合いができます（下記参照）。

---



## 相方（P2）のロックオン操作

P2 のロックオンは **ゲーム本体のロックオンがそのまま P2 視点で動きます**。P1 と同じ感覚で使えます：

- **ロックオン（ゲーム内のボタン設定どおり）** — 押している間、ターゲットを固定します。
離すと通常の自動ターゲット（近くの敵を自動で狙う）に戻ります。
- **ターゲット切替** — こちらもゲーム内の操作どおり、ロックオン中に次の対象へ切り替えられます。
- ボタンはゲーム本体のボタン設定に従うため、トレーナー側の専用設定はありません。
- **P2 にも照準マークが出ます** — P2 のロックオン対象に本物の照準マークが表示されます
（Splitscreen 中は上画面 = P1 の照準 / 下画面 = P2 の照準、と画面ごとに分かれます）。
- Splitscreen 中は、ロックオンすると **P2 のカメラが対象を正面に捉えるように追尾**します
（強さは「カメラ調整」→「ロックオン追尾」で変更、0 で無効）。

---



## ダウンと自動蘇生

- 片方が倒れても、**相方が生きていればゲームオーバーになりません**。ダウンして数秒待つと自動で復活します。
- 蘇生までの残り時間は画面に **カウントダウン表示**されます（P1 は左下・P2 は右下）。
- **「ダウン秒数」「蘇生 HP」** スライダーで、待ち時間と復活時の HP を調整できます。
- **2 人同時に倒れると通常どおりゲームオーバー**。

---



## Friendly Fire / PvP（対戦）

- **Friendly Fire** — P1/P2 のお互いの攻撃が当たるようになります。
- **PvP**（Friendly Fire ON 中のみ）— お互いを**ロックオン**でき、**エネミーステップ**（相手踏み）も可能に。
タイマン対戦用です。PvP 中の蘇生は常に HP 全快です。
- **攻撃力補正** —敵へ与えるダメージの倍率を調整できます
（PvP の対人ダメージには影響しません）。

---



## 相方（P2）のワープ

グリムグリップなどのギミック移動で相方が置き去りになったら、**「P2 を P1 の位置へ」ボタン**
（または既定 **HOME** キー、変更可）で P1 の隣へテレポートさせられます。

さらに、次の場面では**自動でワープ**します（操作不要）：

- **ボス戦が始まったとき** — ボスが登場したら P2 を P1 の隣へ呼び寄せます。
- **強制戦闘が始まったとき** — 扉がロックされる戦闘の開始時、P2 が離れた場所にいたら
呼び寄せます（すぐ近くにいるときは何もしません）。

ボスエリアや戦闘エリアの外に P2 が締め出されて合流できなくなる事故の対策です。

---



## カメラの調整

「Co-op」内の **「カメラ調整」** を開くと、見やすさを好みに合わせられます。


| 項目                   | 説明                               |
| -------------------- | -------------------------------- |
| 引きの強さ                | 2 人（や敵）が離れるほどカメラを引く量。大きいほどよく引きます |
| 最小 / 最大ズーム           | 引きの下限 / 上限                       |
| （通常時 / ロックオン中 / ボス戦） | それぞれ別に調整できます                     |
| 追従の滑らかさ              | カメラの動きの滑らかさ。小さいほどゆっくり追従          |
| 固定カメラの追従倍率           | 固定アングルのカメラで 2 人へ寄せる量。動きすぎるなら下げる  |
| **リセット**             | カメラ調整の値をすべて初期値に戻す                |


迷ったら **「リセット」** で初期値に戻せます。

## Splitscreen（上下 2 画面分割）

**「Splitscreen (上下 2 分割)」にチェック**を入れると、P2 を召喚した時点で画面が自動的に
**上 = P1 / 下 = P2** に分かれます（P2 を引っ込めると自動で元に戻ります）。

- **下画面は P2 専用の本物のカメラ** — P2 側もゲーム本体のカメラ処理で動きます（見え方・
操作感は P1 の画面と同じ。壁ずり・角度補正・固定カメラやレールカメラのエリア、ボス戦の
ボスカメラまで、P2 の位置に合わせて切り替わります）。2 本目のコントローラの
**右スティックで見回し**もできます。
- **クラシックカメラ (P2)** — 以前のトレーナー独自の追従カメラ（R3 で背後リセット、
ロックオン追尾の強さ調整など）に戻したい場合は、Splitscreen 配下のチェックで切り替えられます。
- **照準マークも画面ごとに自分のもの** — 上画面には P1 の、下画面には P2 のロックオン照準が
それぞれ表示されます。
- **P2 の移動は自分の画面基準** — 左スティックは P2 のカメラ向きに合わせて動きます。
- ポーズ・イベントシーン・ロード中は自動で分割を解除し、終わると自動で復帰します
（**味方がダウンして蘇生待ちの間は分割を維持**します）。
- 分割中は **上画面に P1 の HUD だけ、下画面に P2 の HUD だけ**が表示されます。
- 通常のカメラ（2 人を 1 画面に収める方式）とは排他です。分割中はそちらが自動で OFF になります。

> ⚠️ 画面を 2 回描画するため **GPU 負荷はほぼ 2 倍**になります。重い場合は解像度や画質を下げてください。

---



## 相方（P2）の HUD

Co-op を ON にすると、相方の HP・ゲージ・武器表示が **ゲーム本体の HUD そのもの**で
もう 1 セット自動表示されます（「Co-op HUD」チェックで個別に on/off も可能）。

位置を変えたいときは **「HUD 位置調整」** を開きます：

- **P1 HUD / P2 HUD** それぞれの **X 位置 / Y 位置 / スケール** を調整できます。
- **「武器 HUD の個別調整」** で、武器表示（ダンテの Devil Arm / Fire Arm、バージル・レディの武器アイコン）
だけをさらに細かく動かせます。
- 配置は**通常時と Splitscreen 中で別々に記憶**され、分割の on/off に合わせて自動で切り替わります
（スライダーは「今表示されている方」を編集します）。
- 調整した値は**自動保存**され、次回起動時に復元されます。「リセット」で初期配置に戻せます。

---



## うまくいかないときは

- **相方が出てこない / 動かない**
  - 「Co-op (P2)」が ON か、P2 のキャラが選ばれているか確認
  - 2 本目のコントローラが認識されているか確認
- **直後にクラッシュする / 不安定**
  - セーブデータをロードしてから使う（リソースの読み込みのため）
  - まずはトレーニングモードなど安全な場所で試す
- **ステージ移動の直後は**、相方が出るまで一瞬（約 0.5 秒）かかります

---



## 注意点・既知の制限

- 相方は **1 人まで**（コントローラ 2 本での 2 人プレイ）。
- Splitscreen 中、ボスの HP バーやミッションタイマーなど一部の共通表示は**両方の画面に**表示されます。
- 一部の組み合わせ・場所で挙動が乱れることがあります。
