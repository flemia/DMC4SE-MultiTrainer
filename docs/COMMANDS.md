# 追加技 コマンド表

Character タブ → 「Character specific」の各キャラのタブで ON にした技のコマンド一覧です。
ON / OFF の状態は保存され、次回の起動時もそのまま使えます。

## 表記


| 表記      | 意味                                                        |
| ------- | --------------------------------------------------------- |
| ロックオン   | ロックオンボタンを押したまま                                            |
| 前 / 後   | ロックオンしている敵の方向へスティックを倒す / 敵と反対方向へ倒す                        |
| 後→前     | 後に倒してから前に倒す (Heavy Rain / Nero のキャリバーと同じスティック操作)          |
| 攻撃      | 近接攻撃のボタン (Nero・Dante・Vergil・Trish の剣のボタン、 Lady は同じ位置のボタン) |
| 地上 / 空中 | その場所でだけ出せる                                                |
| +       | 同時に / 続けて入力                                               |

## Nero


| 技                     | 条件                | コマンド                        | 内容                                                               |
| --------------------- | ----------------- | --------------------------- | ---------------------------------------------------------------- |
| **Free Table Hopper** | 地上 / 空中           | ロックオン + ジャンプ + 方向 (回避)      | 敵の攻撃にタイミングを合わせなくても、 回避が毎回 Table Hopper になります。 スキルを買っていなくても使えます。  |
| **Spirit Mode**       | いつでも (DT 中でなくても可) | 割り当てたキー / パッドのボタンで ON / OFF | ON の間、 Devil Bringer ボタンで魔人を動かします (下の表)。 Nero のバスター / スナッチは出ません。 |




### Spirit Mode 中の Devil Bringer


| コマンド                        | 内容                                                                    |
| --------------------------- | --------------------------------------------------------------------- |
| Devil Bringer               | 魔人が敵 (ロックオン中の敵、 いなければ一番近い敵) へ飛んで斬りかかります。 続けて押すとコンボになります。 空中の敵には空中コンボ。 |
| ロックオン + 後 + Devil Bringer   | 打ち上げ (High Roller)                                                    |
| ロックオン + 前 + Devil Bringer   | 地上ではスティンガー、 空中ではスプリット                                                 |
| ロックオン + 後→前 + Devil Bringer | キャリバー                                                                 |

## Dante


| 技                   | 条件                      | コマンド                | 内容                                                                                |
| ------------------- | ----------------------- | ------------------- | --------------------------------------------------------------------------------- |
| **Round Bounce**    | リベリオン装備中 / 地上・空中        | ロックオン + 後→前 + 攻撃    | 溜めなしで Round Trip を出します。 剣が同じ敵に 2 回当たると、 その敵が Dante の方へ飛んできます。 剣を投げた後はすぐに動けます。     |
| **Air Upper Slash** | Dark Slayer スタイル / 空中のみ | ロックオン + 後 + スタイルボタン | 閻魔刀で敵を斬り上げます。 Dark Slayer の空中コンボ 1 / 2 段目の後からも出せます。 空中で 1 回 (着地かエネミーステップでまた使えます)。 |

## Vergil


| 技               | 条件                 | コマンド                              | 内容                                                                                                          |
| --------------- | ------------------ | --------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| **Daemon Pull** | 幻影剣が刺さった敵がいるとき     | ロックオン + 後→前 + Trick ボタン           | 幻影剣が刺さっている敵を Vergil の正面へ引き寄せ、 同時に幻影剣を 1 本撃ちます。 Vergil は動きません。 ボスと大型の敵は対象外です。                                |
| **Zettou (絶刀)** | ヤマト装備 + 魔人化 (DT) 中 | ロックオン + 後 + Trick ボタン + 攻撃 (同時押し) | 次元斬・絶の動きが変わり、 姿を消している間に次元斬を連続で撃ち込みます。 1 発ごとに DT を消費し、 DT が続く限り撃ち続けます (最低 5 発)。 敵がいなくなったら、 そこで撃つのをやめて戻ってきます。 |

## Trish


| 技               | 条件   | コマンド             | 内容                                                     |

## Lady


| 技               | 条件          | コマンド                  | 内容                                                                           |
| --------------- | ----------- | --------------------- | ---------------------------------------------------------------------------- |
| **Wire Snatch** | ロックオン中      | ワイヤーショットを敵に当てる        | 敵を Nero のスナッチのように Lady の正面へ引き寄せます。 ボスと大型の敵は対象外です。 ロックオンなしのワイヤーショットはいつもどおりです。 |
| 〃 (Lady が跳ぶ)    | 空中 / ロックオン中 | 前を入れながらワイヤーショットを敵に当てる | 逆に Lady が敵の方へ跳んでいきます。                                                        |
| **Air Scatter** | 空中のみ        | ロックオン + 後 + 攻撃        | 手りゅう弾を 1 個投げます。 敵に触れるとその場で爆発し、 敵を真上に打ち上げます。 投げた後のモーションは 2 段ジャンプでキャンセルできます。   |
